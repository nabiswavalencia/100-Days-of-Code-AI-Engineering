# 100 Days of Code: AI Engineering Journey

Welcome to my **100 Days of Code: AI Engineering Journey**.

This repository documents my 100-day commitment to learning, building, experimenting, and improving across the main foundations of AI engineering. I am using this journey to develop practical skills in Python, JavaScript, data, machine learning, deep learning, generative AI, AI agents, web development, deployment, and MLOps.

The goal is not to learn one AI tool or simply complete tutorials. The goal is to build myself step by step and develop the ability to create AI systems that solve real problems.

## Why I am doing this

It has been four months since my final-year exams, and during this time I have been learning about artificial intelligence, building projects, and exploring different technologies.

Through this process, I have realized that becoming an AI engineer is not about learning one framework, library, or AI tool. It is about developing a combination of programming, mathematical, data, machine-learning, software-engineering, web, and deployment skills.

This repository is my way of making that process visible and accountable. It will contain my daily progress, notes, experiments, projects, mistakes, solutions, and reflections.

## My learning roadmap

The journey follows this sequence:

```text
Python & Software Engineering
              ↓
Mathematics & Data
              ↓
Machine Learning
              ↓
Deep Learning
              ↓
Generative AI
              ↓
AI Agents
              ↓
Deployment & MLOps
              ↓
Real Projects
```

### 1. Python and software engineering

I will strengthen my programming foundations through Python, Git, APIs, SQL, testing, packaging, error handling, logging, and problem-solving.

The aim is to move beyond writing isolated scripts and learn how to create code that is structured, understandable, reusable, and maintainable.

### 2. Mathematics and data

I will study the practical mathematical and data foundations behind AI, including linear algebra, probability, statistics, NumPy, pandas, data cleaning, exploratory data analysis, and data visualization.

### 3. Machine learning

I will learn regression, classification, clustering, feature engineering, model selection, cross-validation, evaluation metrics, experiment tracking, and reproducible machine-learning pipelines.

### 4. Deep learning

I will explore neural networks, training loops, optimization, CNNs, transfer learning, NLP, transformers, and PyTorch through focused experiments and small projects.

### 5. Generative AI

I will learn about large language models, prompt engineering, tokenization, embeddings, vector databases, retrieval-augmented generation, structured outputs, fine-tuning, and multimodal AI.

### 6. AI agents

I will explore how AI systems can use tools, APIs, databases, memory, and workflows to complete meaningful tasks. I will begin with simple, controlled tool use before attempting more complex agentic systems.

### 7. Deployment and MLOps

I will practice FastAPI, Docker, GitHub Actions, cloud deployment, environment variables, health checks, logging, monitoring, evaluation, and basic production-readiness practices.

### 8. Real projects

The most important part of this journey is building. I do not want to only watch tutorials or collect information. I want to create practical systems such as AI assistants, RAG applications, automation tools, AI agents, recommendation systems, and other applications that solve real problems.

## My main project

Throughout the journey, I will develop one cumulative project: a **domain-specific AI assistant**.

The project will gradually evolve through the following stages:

1. A simple data and prediction experiment.
2. A tested Python backend with a FastAPI endpoint.
3. A JavaScript web interface connected to the backend.
4. A reproducible machine-learning pipeline.
5. A document-ingestion and embedding workflow.
6. A retrieval-augmented generation assistant with citations.
7. A controlled tool-using workflow.
8. A containerized and deployed application.
9. An evaluated, documented, and portfolio-ready capstone.

The exact domain may develop as I learn more, but the project will be selected around a practical problem and a clearly defined group of users.

## Python and JavaScript together

Python is the main language for my AI engineering work. I will use it for data processing, machine learning, deep learning, APIs, RAG pipelines, evaluation, and deployment.

JavaScript will support the web-development side of the journey. I will use it to create accessible and useful interfaces for the AI systems I build. This includes HTML, CSS, JavaScript fundamentals, DOM manipulation, API requests, form handling, loading states, error handling, responsive design, and frontend deployment.

The purpose of combining both languages is to learn how an AI system becomes a usable product:

```text
Data and models → Python backend → API → JavaScript interface → User feedback
```

## My rules

### Rule 1: Code for at least two hours every day

My minimum commitment is two hours of coding every day. On weekdays, I may spend up to five hours. On weekends, I will maintain a two-hour coding block.

### Rule 2: Document daily progress

Every day, I will record what I worked on, what I learned, what confused me, what failed, and what I plan to do next.

### Rule 3: Document the journey

This repository will contain more than finished projects. It will also contain notes, experiments, debugging lessons, decisions, reflections, and evidence of improvement.

## My working mindset

```text
Learn → Build → Break → Fix → Deploy → Improve
```

I expect some days to be productive and clear, while other days may involve confusion, failed experiments, bugs, or slow progress. Those difficulties are part of the journey.

The objective is not to create a perfect record. The objective is to remain consistent, understand what I am doing, solve problems, and keep moving forward.

## What success looks like

By the end of the journey, I want to be able to:

- Explain the main components of an applied AI system.
- Write clean Python and JavaScript code for a practical project.
- Prepare, analyze, and transform data.
- Build and evaluate classical machine-learning models.
- Understand and run basic deep-learning experiments.
- Use transformer models and embeddings.
- Build a RAG system with citations.
- Connect an AI backend to a web interface.
- Validate outputs and test AI-system behavior.
- Package and deploy an application.
- Document technical decisions, limitations, and results.
- Present a working project clearly to other people.

Success does not mean mastering every part of AI in 100 days. It means building a strong foundation, completing a meaningful project, and developing the discipline to continue learning beyond this challenge.
