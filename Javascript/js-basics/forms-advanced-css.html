Form basics

A <form> groups inputs together. Every input should have a matching <label> - clicking the label focuses the input, and screen readers announce it.

Client-side validation

Attributes like required, pattern, minlength/maxlength and min/max let the browser validate for free. form.checkValidity() and input.setCustomValidity() hook into that system from JS instead of reinventing it.

novalidate is on this form on purpose, so the demo JS can run its own check and show the messages below instead of the browser's native popups.

Advanced CSS: custom properties

CSS variables (--name) are declared once on :root and reused everywhere with var(--name), instead of repeating the same color or spacing value across the stylesheet.

  • :nth-child(odd) - pick every other sibling
  • .parent > .child - direct child combinator, vs .parent .child (any descendant)

Advanced CSS: transitions & animation
