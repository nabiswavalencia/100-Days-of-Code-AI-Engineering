# Day 21 — SQL Fundamentals (Research)

Mostly a research day today, so this is a short one.

## What I learned
- `SELECT` / `FROM` — choosing columns and specifying the table to query.
- `WHERE` — filtering rows by a condition.
- `DISTINCT` — removing duplicate values from results.
- `ORDER BY` — sorting results ascending or descending.
- `LIMIT` — capping the number of rows returned.
- `AND` / `OR` / `NOT` — combining or negating conditions.
- Comparison operators: `=`, `>`, `<`, `>=`, `<=`, `<>`.
